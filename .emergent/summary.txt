**original_problem_statement**: The user wants to build a comprehensive cricket coaching mobile app named PerfectPractice for iOS, Android, and Web.

**PRODUCT REQUIREMENTS:**
The application should function as a digital coach and performance journal with the following key features:
- **User Authentication:** Standard email/password registration and login, augmented with social login options (Google, Apple, Facebook, Twitter).
- **Onboarding Flow:** A multi-step process after the first login to collect user data like height, weight, and experience level (beginner, intermediate).
- **Session Management:**
    - Create practice sessions with configurable parameters: number of players (1-10, with 1 being solo mode), focus area (batting, bowling, fielding), duration, and skill level.
    - Solo sessions should start immediately. Multi-player sessions require a join code and wait for all participants.
    - The session host controls the flow (start, next step, complete).
    - An option to delete sessions (host only).
- **Structured Practice:**
    - Sessions are automatically structured with a mandatory 10-minute warm-up and a 10-minute cool-down.
    - **Instructional Videos:** Each practice step should display demonstration videos (e.g., how to hold the grip, batting stance). The user will provide these videos (YouTube or direct upload).
- **AI-Powered Coaching:**
    - **AI Practice Plans:** If a user doesn't specify a goal, the app should generate a rule-based practice plan based on their skill level and focus area.
    - **AI Shot Analysis:** Users can upload videos of their performance. The app should provide AI-driven feedback, initially rule-based, with a plan to evolve to use computer vision (via Emergent LLM Key).
- **Advanced Features (User requested all be implemented):**
    - **Analytics & Progress Tracking:** Dashboards, charts, weakness heatmaps, and streak tracking.
    - **Session Templates:** Allow users to save and reuse favorite practice routines.
    - **Goals & Achievements:** Users can set personal goals and unlock badges.
    - **Social & Team Features:** Team/squad management, coach-player links, and leaderboards.
    - **Video Enhancements:** In-app recording and side-by-side video comparison.
    - **UX Improvements:** Onboarding tutorial, calendar view, PDF reports, and a dark/light theme.

**User's preferred language**: English
